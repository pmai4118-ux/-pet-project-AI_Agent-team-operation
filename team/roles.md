# Vai trò trong phòng ban

Mỗi vai mô tả một trách nhiệm. Codex hoặc Antigravity có thể đảm nhận vai phù hợp với ticket và quyền được cấp.

| Vai | Trách nhiệm | Đầu ra |
| --- | --- | --- |
| Product Owner | Chọn ưu tiên, chốt phạm vi, nghiệm thu | Quyết định và tiêu chí |
| PM / BA | Làm rõ yêu cầu, chia việc và theo dõi phụ thuộc | Ticket có phạm vi và tiêu chí kiểm tra được |
| Tech Lead / Architect | Thiết kế và phân việc kỹ thuật | Quyết định kỹ thuật, kế hoạch tích hợp |
| UX / UI | Thiết kế luồng người dùng và trạng thái màn hình | Luồng, mô tả giao diện và điểm cần kiểm tra |
| Frontend | Triển khai hành vi giao diện | Mã nguồn và test liên quan |
| Backend | Triển khai API, nghiệp vụ và lưu trữ | Mã nguồn, hợp đồng API và test |
| Mobile | Triển khai và xác minh trên thiết bị mục tiêu | Bản thay đổi và kết quả kiểm tra thiết bị |
| Data / AI | Xây luồng dữ liệu hoặc tính năng AI, đo chất lượng | Dữ liệu, quy trình xử lý hoặc kết quả đánh giá |
| QA | Tự chạy ca nghiệm thu và tái hiện lỗi | Bằng chứng test và báo cáo lỗi |
| Code Review | Đọc diff và kiểm tra tính đúng, khả năng bảo trì | Nhận xét có dẫn vị trí và cách tái hiện |
| Security | Rà soát quyền, dữ liệu và rủi ro bảo mật | Phát hiện, tác động và cách kiểm chứng |
| DevOps / SRE | Chăm sóc CI/CD, quan sát hệ thống và phục hồi | Kiểm tra build, kế hoạch triển khai hoặc rollback |
| Technical Writer | Viết hướng dẫn sử dụng và vận hành | Tài liệu được đối chiếu với hành vi thực tế |

Ở TECH-001, Codex kiêm PM/BA, Tech Lead và Frontend. Antigravity nhận QA và Code Review. Gemini Web có thể phản biện UX hoặc tiêu chí nghiệm thu nếu có câu hỏi cụ thể.
